铜像纪念地湖南 · 湘潭·韶山

韶山毛泽东铜像广场

1993 年，为纪念毛泽东诞辰 100 周年，韶山立起这尊通高 10.1 米的铜像。揭幕前后，当地流传着“日月同辉”、寒冬杜鹃绽放等说法。

1993 年地图定位 →
塑像黑龙江 · 哈尔滨

哈尔滨爱建社区城市源广场

这尊塑像原在哈尔滨车辆厂。上世纪 80 年代，职工没有把它砸毁，而是整体放倒、埋入地下；2002 年开发建设时，它又被挖出重立。

20 世纪 60 年代地图定位 →
塑像新疆 · 喀什

喀什人民广场

当地流传着这样一个故事：上世纪 80 年代各地陆续拆除毛泽东塑像时，喀什的维吾尔族市民自发围在塑像周围保护，使它得以保留。

1969 年地图定位 →
塑像江苏 · 南京·栖霞

南京十月村毛主席塑像广场

1956 年 1 月，毛泽东视察南京十月村；1967 年，村民在当年他站立的地方集资建起塑像。它后来成为市级文物保护单位。

1967 年地图定位 →
塑像湖南 · 长沙

橘子洲青年毛泽东雕塑

雕塑高 32 米、长 83 米，由 8000 多块永定红花岗岩拼接，表现 1925 年在橘子洲头思考中国命运的青年毛泽东。

2009 年地图定位 →
铜像纪念地河北 · 石家庄·平山

西柏坡纪念馆

1948 年，中共中央来到西柏坡，在这里指挥三大战役、召开七届二中全会。广场上的五大书记铜像，纪念“新中国从这里走来”的岁月。

HOW TO USE

三步，开始一趟纸上寻访

地图不是路线推荐，也不代表官方立场。它更像一本可以缩放的地方志，供你按图索骥、继续查证。

选一个范围

按分类、省份、年代筛选，或直接搜索地名、人名、口号和故事关键词。

点开一个标记

查看地址、年代、材质和“背后的故事”，再决定它是否值得专程去看。

出发前再核实

一键跳转高德、百度或 OSM。校园、军校、场馆和营区，请先确认是否对外开放。

DATA & BOUNDARIES

这是一张民间地图，不是官方名录

公开资料中没有全国现存塑像的权威统计；本图按公开报道、校史、地方文物信息整理，难免遗漏或过时。甘肃、西藏暂未收录到可核实的大型室外塑像点位，地图留空，不代表当地没有。坐标是近似值，塑像可能迁移、拆除或修缮。

OPEN SOURCE

一张可以一起修订的地图

页面、地图和故事生成脚本全部开源。发现错漏、迁移或新的点位，欢迎通过 GitHub Issue 提交线索。

01 / STATIC

纯静态，打开即用

单文件 Leaflet 地图，配合高德瓦片与 marker clustering，不需要后端服务。

02 / READABLE

数据可读、可复现

所有点位写在 map.html 中，故事档案由 Node 脚本生成，方便审阅与批量修订。

03 / CORRECTABLE

欢迎纠错与补充

这不是定本。迁移、关闭、拆除、年代修正，或你身边被遗漏的一处，都可以提交。
