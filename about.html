ABOUT THE PROJECT

关于这张民间地图

它不是官方名录，也不是一次完成的“全国普查”。它是一份持续修订的公开索引：把散落在报道、校史、地方文物信息与纪念馆展陈里的地点，放回同一张地图。

项目是什么

“山河印记”是一张中国大陆毛泽东塑像、铜像、纪念地与相关标语题词的交互地图。它把公开可见的室外塑像、纪念馆/故居、革命旧址与标语景观放在同一套坐标体系里，并为每个地点配一段背景故事。

项目目前收录 99 处地点，覆盖 29 个省级行政区，其中 33 处标为重点。数据版本为 2026 年 11 月。

这张地图的目标不是给出“标准答案”，而是降低查证成本：先让你知道哪里有、大概什么年代、背后发生了什么，再带着问题去现场或档案馆继续核对。

收录标准

收录范围限定为中国大陆境内，优先选择公开资料可核实、目前仍有实物或遗址可寻的点位：

  • 室外塑像/铜像：校园、广场、厂区、纪念地中的大型毛泽东雕像，重点是 1960—1970 年代建造、目前仍存者。
  • 纪念地：毛泽东故居、旧居、会址、纪念馆、革命旧址，以及与他生平重要事件直接相关的场所。
  • 标语题词：城楼、会址、厂区、校园等公共空间中仍可见的毛泽东语录、题词和时代标语景观。
  • 校园点位：主要依据 2018 年网络流传的“35 所大学”名单，并结合校方资料与公开报道核对；名单此后可能有调整。

不追求收录室内小型像、私人收藏、纪念章、印刷品等；也不把仅有文字记载、已无实物可寻的点位作为重点。一个地点可能同时属于多个类别，例如“铜像 + 纪念地”，因此分类计数会重叠。

故事怎么写

每个地点的“背后的故事”侧重人物、事件与地方记忆，而不是塑像尺寸。写作时优先使用可公开查证的资料：新闻报道、校史、地方志、纪念馆展陈与地方文物部门信息。对于校园、厂区等公开资料较少的点位，只写到可核实的大背景，不虚构具体人物或情节。

涉及民间传说、口述记忆或不同说法的内容，文中会用“相传”“当地流传”“据当地资料”等字样提示。例如喀什塑像在 1980 年代被市民围护的故事，就属于地方记忆，而不是档案定论。读者应把这些段落当作继续查证的线索，而不是最终结论。

坐标与年代

坐标采用 WGS-84 近似值，校园、广场、厂区类点位通常标在主要出入口或雕像所在的大致位置，不保证能直接走到像前。底图使用高德地图（GCJ-02），页面脚本已做坐标纠偏；卫星影像同样来自高德。

年代字段对塑像一般指落成年代，对旧址、纪念馆则指相关历史年代，仅作浏览与筛选参考。部分点位的建造年代在公开资料中说法不一，地图取较常见的一种；如果你掌握更准确的碑刻、档案或校史信息，欢迎指正。

“高德导航”“百度地图”“OSM”按钮会跳转到对应平台。由于坐标是近似值，实地导航请以导航软件搜索到的地点名称为准，不要直接以地图上的标记点作为唯一依据。

已知局限

  • 不是完整名录。公开资料中没有任何一份“全国现存毛主席塑像”权威统计；本图必然有遗漏，也可能包含已经迁移、拆除或不再公开可见的点位。
  • 现状会变化。塑像可能因城市改造、校园建设、文物保护或单位管理而移动、围挡、修缮或关闭。地图更新有滞后。
  • 开放信息不完整。校园、军校、营区、医院、厂区等点位不一定对公众开放。地图标注“可见”不等于“可进入”，请尊重现场管理。
  • 故事存在不同版本。同一事件在不同报道、口述与地方记忆中可能有细节差异；文中已尽量提示不确定性，但仍可能有误。
  • 不是官方立场。本项目为民间整理，仅供参观、研究与学习参考，不代表任何机构或官方立场。

图片与版权

页面中的实景照片全部为公开网络检索所得，用于呈现各地点当前的样貌；每张图的右下角标注了来源站点，可点击回到原页面。项目本身不对这些照片主张任何权利，版权归原作者或原发布机构所有。

  • 照片仅用于地点介绍与背景说明，不作商业用途；
  • 如你是某张照片的权利人且不希望它出现在这里，请在 GitHub 提 Issue 或发邮件说明，我会在确认后立即删除；
  • 部分照片可能拍摄于数年前，塑像或周边环境已发生变化，实地情况请以现场为准；
  • 受检索条件限制，少数点位（如哈尔滨爱建社区城市源广场、山东省立医院、上海理工大学、友谊县龙谊集团）暂未找到可用的实景图，因此没有配图。

底图瓦片由高德地图提供，Leaflet 与 Leaflet.markercluster 以本地文件方式随站点分发（BSD-2-Clause / MIT）。

如何贡献

这是一个开源项目，欢迎纠错、补充和修订。你可以通过 GitHub Issues 提交：

  • 点位的迁移、拆除、关闭或重新开放；
  • 更准确的地址、坐标、建造年代、材质与尺寸；
  • 遗漏的塑像、铜像、纪念地或标语题词；
  • 故事中的事实错误、不同说法或可补充的一手来源；
  • 页面显示、移动端适配或无障碍方面的改进。

提交一条线索

最好附上地点名称、省市县/区、大致坐标或地址、年代、现状，以及至少一条可核实的来源链接。若涉及校园、军校、营区等不开放场所，请只提供公开信息，不要拍摄或发布不允许公开的内容。
